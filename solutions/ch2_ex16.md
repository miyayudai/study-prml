# 演習問題 2.16: 無相関性と独立性

本演習問題では、2つの確率変数が「無相関（uncorrelated）」であっても、必ずしも「独立（independent）」であるとは限らないことを具体的な反例を通して示します。

## 1. 独立性と無相関性の定義

2つの確率変数 $x, y$ について、それぞれの定義は以下の通りです。

- **独立性 (Independence):** 同時確率分布が周辺分布の積に分解できること。
  $$ p(x, y) = p(x)p(y) $$
  独立である場合、任意の関数 $f(x), g(y)$ に対して $\mathbb{E}[f(x)g(y)] = \mathbb{E}[f(x)]\mathbb{E}[g(y)]$ が成り立ちます。

- **無相関性 (Uncorrelatedness):** 共分散が $0$ になること。
  $$ \text{cov}[x, y] = \mathbb{E}[xy] - \mathbb{E}[x]\mathbb{E}[y] = 0 $$
  すなわち、$\mathbb{E}[xy] = \mathbb{E}[x]\mathbb{E}[y]$ となることです。

独立であれば無相関になりますが、その逆は一般には成り立ちません。

## 2. 反例の構築

無相関であるが独立ではない例として、次のような確率変数を考えます。

確率変数 $x$ を区間 $[-1, 1]$ 上の一様分布に従うとします。
$$ x \sim \mathcal{U}(-1, 1) $$
このとき、確率密度関数は $p(x) = \frac{1}{2} \ (-1 \le x \le 1)$ です。

もうひとつの確率変数 $y$ を、$x$ の2乗として完全に決定論的に定義します。
$$ y = x^2 $$

明らかに $y$ は $x$ に完全に依存しているため、$x$ と $y$ は**独立ではありません**。$x$ の値が分かれば、$y$ の値は一意に定まります。

## 3. 共分散の計算

次に、$x$ と $y$ の共分散を計算し、これらが無相関であることを示します。

まず、$x$ の期待値を求めます。
$$
\mathbb{E}[x] = \int_{-1}^{1} x \frac{1}{2} dx = \left[ \frac{x^2}{4} \right]_{-1}^{1} = 0
$$

次に、$x$ と $y$ の積 $xy$ の期待値を求めます。$y = x^2$ より $xy = x^3$ です。
$$
\mathbb{E}[xy] = \mathbb{E}[x^3] = \int_{-1}^{1} x^3 \frac{1}{2} dx = \left[ \frac{x^4}{8} \right]_{-1}^{1} = 0
$$

最後に共分散を計算します。
$$
\text{cov}[x, y] = \mathbb{E}[xy] - \mathbb{E}[x]\mathbb{E}[y] = 0 - 0 \cdot \mathbb{E}[y] = 0
$$

したがって、共分散は $0$ となり、$x$ と $y$ は**無相関**であることが示されました。

## 4. 結論

以上の具体例から、2つの確率変数 $x$ と $y$ が無相関（線形な関係がない）であっても、独立である（一切の依存関係がない）とは限らないことが明確に示されました。共分散はあくまで「線形な依存関係」のみを測る指標であるため、$y = x^2$ のような非線形な強い依存関係がある場合でもゼロになり得る点に注意が必要です。
